# QUCNET PAPER REPRODUCTION AND CONTROLLED ABLATION COMPLETED

Objective:
Complete the reproduction of the QuCNet thyroid nodule classification methodology and evaluate whether quantum-transformed feature maps provide an advantage over original grayscale ultrasound images.

Method:
The complete pipeline was implemented using the public DDTI dataset, including dataset inspection, XML parsing, preprocessing, train-test splitting, class balancing, quantum feature generation, QuCNet implementation, classical baselines and reproducibility audits.

For the final six-class TI-RADS comparison, two controlled models were evaluated:

1. Paper-structured QuCNet classifier operating on 64×64×4 quantum feature maps.
2. Equivalent classical CNN operating on original grayscale ultrasound images.

Both models used the same original 279 training samples, identical train-validation indices, identical class weights, the same optimizer, learning rate, batch size and untouched 70-image test set.

Results:

Quantum TI-RADS Model:
Accuracy          : 18.57%
Balanced Accuracy : 15.16%
Macro F1-Score    : 6.72%
Weighted F1-Score : 8.74%

Classical TI-RADS Model:
Accuracy          : 24.29%
Balanced Accuracy : 28.09%
Macro F1-Score    : 23.18%
Weighted F1-Score : 22.76%

Majority-Class Baseline:
Accuracy          : 27.14%

Observation:
The quantum model showed near-prediction collapse and used only three of the six output classes. The classical model predicted all six classes and achieved substantially better balanced accuracy and F1-scores, although its overall accuracy remained below the majority-class baseline.

Conclusion:
The available QuCNet methodology and processing pipeline were successfully implemented. However, the numerical performance reported in the original paper could not be reproduced using the publicly available DDTI dataset and disclosed implementation details.

Major limitations identified were missing original pathology labels, incomplete architecture and quantum-circuit specifications, small class sizes and strong visual similarity between adjacent TI-RADS categories.

The controlled comparison did not demonstrate an advantage from quantum-transformed features over original grayscale images. The reproduction stage is now complete. Any further experiments will be presented separately as proposed improvements and not as part of the original reproduction.

POST-REPRODUCTION DATASET AND SPLIT AUDIT INITIATED
=========================================================

After completing the initial QuCNet reproduction and the controlled comparison
between quantum-transformed features and classical grayscale images, I reviewed
the complete experimental pipeline once again.

During this review, I identified an important methodological concern. The DDTI
dataset contains multiple ultrasound images for several cases, and some images
also contain multiple annotated nodule regions. Therefore, an image-level
train-test split alone may not guarantee patient-level independence.

If images or regions belonging to the same case are placed in different
partitions, the model may indirectly receive information from the same patient
during both training and testing. This can produce data leakage and may lead to
overestimated performance.

I therefore decided that the initial image-level experiments should be treated
as exploratory reproduction experiments. Before closing the reproduction
study, I initiated a complete case-level and annotation-level audit.

Important Clarification
-----------------------

The earlier Benign/Malignant labels were not pathology-confirmed diagnosis
labels. I had constructed them as provisional binary proxy labels using the
available TI-RADS categories because the public DDTI dataset did not contain
the pathology mapping required by the original paper.

These binary experiments remain valuable because they demonstrate the
limitations of reproducing the reported tumor-classification task using the
public dataset. However, they cannot be presented as an exact pathology-based
reproduction.

Decision
--------

I decided to perform a complete audit of:

1. Case-to-image relationships
2. XML annotation structures
3. Multiple images belonging to the same case
4. Multiple regions belonging to the same image
5. Valid and invalid annotation coordinates
6. Previous train-test assignments
7. Case-level leakage across dataset partitions

This audit was necessary to produce a final experimental pipeline that is
scientifically defensible and reproducible.

PHASE 13 COMPLETED – LESION ROI DATASET PREPARATION
=========================================================

Objective
---------

The objective of Phase 13 was to prepare a lesion-focused TI-RADS dataset using
the expert-marked annotation regions and the frozen case-level split.

Reason for ROI-Based Preparation
--------------------------------

The earlier experiments used complete ultrasound images. However, the DDTI XML
files provide expert-marked nodule boundaries. Using these annotations allows
the model to focus directly on the thyroid lesion rather than learning from
irrelevant background regions, text overlays or surrounding ultrasound tissue.

ROI Processing Procedure
------------------------

For each valid annotation region, I performed the following operations:

1. Loaded the original ultrasound image
2. Read the expert annotation coordinates
3. Calculated the nodule bounding box
4. Added approximately 10 percent contextual margin
5. Cropped the lesion region
6. Converted the crop to grayscale
7. Applied square padding to preserve lesion geometry
8. Resized the padded crop to 64 × 64 pixels
9. Normalized pixel values to the range [0,1]
10. Preserved the case ID, ROI ID and TI-RADS label
11. Saved each partition as reproducible NumPy arrays

PHASE 14 COMPLETED – FINAL LEAKAGE-FREE ROI CATEGORICAL CNN
=========================================================

Objective
---------

The objective of Phase 14 was to perform one final, controlled and
patient-independent six-class TI-RADS baseline experiment using the audited ROI
dataset.

This experiment was designed to determine whether a conventional CNN could
learn meaningful TI-RADS representations when trained only on expert-marked
lesion regions under a strict leakage-free evaluation protocol.

Classification Classes
----------------------

Class 0 → TI-RADS 2
Class 1 → TI-RADS 3
Class 2 → TI-RADS 4a
Class 3 → TI-RADS 4b
Class 4 → TI-RADS 4c
Class 5 → TI-RADS 5

Experimental Controls
---------------------

I used the following controls:

✓ Frozen Phase 12 case-level split
✓ Frozen Phase 13 ROI arrays
✓ Compact CNN architecture suitable for the available dataset size
✓ Training-only image augmentation
✓ Class weights calculated only from the training labels
✓ No SMOTE
✓ No modification of validation or test samples
✓ EarlyStopping
✓ ReduceLROnPlateau
✓ ModelCheckpoint based only on validation performance
✓ Untouched test-set evaluation
✓ Separate ROI-level and case-level analysis

Case-Level Evaluation Method
----------------------------

Because a single case may contain multiple ROI samples, I evaluated the model
at two levels.

ROI-Level Evaluation:
Each nodule region was treated as one prediction sample.

Case-Level Evaluation:
The predicted class probabilities of all ROI samples belonging to the same
case were averaged. The final case prediction was then obtained from the
aggregated probability vector.

This provided a more clinically meaningful patient-level evaluation.

validation performance degraded. This indicated immediate overfitting and weak
generalization.

Observation

The final categorical CNN failed to learn a reliable six-class TI-RADS

The difference between increasing training accuracy and poor validation
performance confirmed that the model was memorizing limited training patterns
instead of learning features that generalized to unseen cases.

Scientific Interpretation
-------------------------

This result is not treated as a coding failure.

The complete pipeline executed successfully:

✓ Dataset parsing succeeded

The poor performance is therefore a valid experimental finding obtained under

Final Reproduction Finding
--------------------------

I was unable to reproduce the high classification performance reported in the
original QuCNet paper using the publicly recoverable DDTI dataset and the
implementation details available in the publication.

The reproduction gap is most likely associated with a combination of:

- Missing pathology-confirmed Benign/Malignant labels
- Possible use of a different or private dataset subset
- Unreported sample-selection criteria
- Incomplete annotation-handling details
- Unreported patient-level split information
- Strong TI-RADS class imbalance
- Very small sample counts in minority categories
- Visual similarity between adjacent TI-RADS classes
- Incomplete quantum-circuit specification
- Incomplete architecture and training specifications
- Possible differences in preprocessing and augmentation

Final Decision
--------------

I decided not to continue adding architectures merely to search for a higher
accuracy value.

Doing so would change the objective from reproduction to performance
optimization and would weaken the scientific clarity of the work.

Therefore:

* The original-paper reproduction is considered complete
* All positive and negative findings will be preserved
* The leakage-free result will be used as the final reproduction evidence
* Earlier image-level experiments will be retained as historical experiments
* Any transfer-learning, ordinal-classification, improved CNN or quantum model
  will be presented separately as an extension and not as part of the original
  paper reproduction

My final description of the model is therefore:

A hybrid quantum-classical QuCNet-style pipeline in which a simulated quantum
circuit generates four-channel image features and a classical neural network
performs classification.

6. WHAT I LEARNED FROM THE COMPLETE REPRODUCTION
---------------------------------------------------------

1. I successfully reconstructed the public DDTI data pipeline from XML files
   and ultrasound images.

2. I confirmed that the public files do not provide the pathology-confirmed
   binary label mapping required for an exact reproduction of the reported
   tumor-classification task.

3. I implemented and verified the PennyLane quantum feature generator.

4. Under matched conditions, the quantum-transformed representation did not
   outperform the original grayscale representation.

5. The controlled six-class quantum and classical models both remained below
   the 27.14 percent majority-class baseline in raw accuracy.

6. Image-level splitting was not sufficient for final patient-independent
   evidence because multiple images and ROIs can belong to the same case.

7. The case-level and geometry-level audits were necessary to obtain a
   defensible final split.

8. Removing the exact duplicate ROI records changed the numerical result but
   did not change the scientific conclusion.

9. The strict classical ROI model did not generalize to unseen cases and
   collapsed to one predicted class.

10. I could not independently reproduce the high performance reported in the
    reference paper using the public dataset and disclosed methodology.
