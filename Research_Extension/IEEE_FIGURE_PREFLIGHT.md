# IEEE figure print-size preflight — QuCNet extension

**Date:** 2026-10-28. **Status:** Existing SVG and PNG figures reviewed; full paper-layout production check remains.

The exact committed SVG files were inspected for width and height. Their corresponding PNGs were visually inspected for axes, legends, tick labels and readability. Full figures are generated by the versioned study scripts and trace back to CSV/JSON source data. SVGs are vector graphics (Matplotlib font outlines), and source PDF exports also exist.

The plotting scripts use 10 pt base Matplotlib text. Simply shrinking the four wide figures to one column would yield base labels of approximately 4.3–4.7 pt, which are not acceptable. Using double-column vector PDF/SVG exports instead produces an estimated 8.9–9.7 pt and preserves crisp lines. The confusion-matrix text would be about 7.6 pt in single-column form and must be proofread at final size.

For the final IEEE LaTeX manuscript, use the vector PDF file in a two-column-spanning figure (figure-star) at textwidth where appropriate. This is a production recommendation, not manuscript creation.
