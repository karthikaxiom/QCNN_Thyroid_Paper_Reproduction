# Processed Dataset Artifacts



This directory stores generated datasets and manifests produced during the

reproduction pipeline.



Typical contents include:



- processed ultrasound arrays,

- quantum-inspired feature arrays,

- encoded labels,

- train-validation-test arrays,

- case identifiers,

- ROI identifiers,

- frozen split manifests,

- dataset summaries,

- and integrity reports.



Large binary arrays such as `.npy` and `.npz` files are intentionally excluded

from Git because they are generated artifacts.



The exact Phase 12 split manifests and lightweight audit records should be

preserved whenever licensing and repository-size constraints allow.
