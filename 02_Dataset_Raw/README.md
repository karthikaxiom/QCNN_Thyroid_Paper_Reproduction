# Raw Dataset



This directory is reserved for the original Digital Database of Thyroid

Ultrasound Images (DDTI).



**Distribution status (audited 2026-10-28):** Contrary to the prior statement in this file, this public repository currently includes **480 tracked raw JPG ultrasound files and 390 tracked XML annotation files** in `02_Dataset_Raw/archive/`. Git ignore rules prevent some future additions but do not remove already-tracked objects or their commit history. The right to independently redistribute these files has **not been established**. See [dataset release decision](../Research_Extension/DATA_RELEASE_PERMISSION_DECISION.md), [rights audit](../Research_Extension/SOURCE_AND_DATA_RIGHTS_AUDIT.md), and [Gate 3 source-data review](../Research_Extension/DDTI_DATA_RIGHTS_AND_PRIVACY_GATE.md). Do not interpret the root software MIT license as a license for DDTI source data. No historical files have been removed or altered.



Users must obtain the dataset separately and preserve the original:



- image filenames,

- XML filenames,

- case identifiers,

- image identifiers,

- lesion annotations,

- and directory relationships.



The source files must be placed here before running the parsing and

dataset-audit stages.



Please refer to the root `README.md` for complete setup instructions.
