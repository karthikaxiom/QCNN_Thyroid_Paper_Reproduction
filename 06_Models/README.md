\# Saved Models



This directory stores model checkpoints generated during the experimental

pipeline.



Typical contents include:



\- QuCNet checkpoints,

\- classical CNN checkpoints,

\- best validation checkpoints,

\- final leakage-free baseline models,

\- model configuration summaries,

\- and training metadata.



Large model files are not committed directly to the repository by default.



The models can be regenerated by following the commands documented in the

root `README.md`.
